# mobility-hire-purchase
Affordable Motorcycle Hire-Purchase

## Live deployment
This site is a static frontend and is ready to deploy to GitHub Pages.

1. Push this project to GitHub.
2. In the repository, open Settings > Pages.
3. Set Source to GitHub Actions.
4. The workflow in `.github/workflows/deploy-pages.yml` will publish the site automatically on pushes to `main`.

The site is designed to be served from the repository root, so the default static hosting setup works without extra build steps.
