# mobility-hire-purchase
Affordable Motorcycle Hire-Purchase

## Live deployment
This site is a static frontend and is ready to deploy to GitHub Pages.

1. Push this project to GitHub.
2. In the repository, open Settings > Pages.
3. Set Source to GitHub Actions.
4. The workflow in `.github/workflows/deploy-pages.yml` will publish the site automatically on pushes to `main`.

The site is designed to be served from the repository root, so the default static hosting setup works without extra build steps.

## Real Supabase setup
This project supports both a demo/local mode and a real Supabase-backed mode.

### 1. Create a Supabase project
- Go to https://supabase.com
- Create a new project
- Copy the project URL and anon key

### 2. Configure the app
Open `supabase-config.js` and set either:

```js
window.MOBILITY_SUPABASE_CONFIG = {
  url: "https://YOUR_PROJECT_REF.supabase.co",
  anonKey: "YOUR_ANON_KEY"
};
```

or set:

```js
window.MOBILITY_SUPABASE_URL = "https://YOUR_PROJECT_REF.supabase.co";
window.MOBILITY_SUPABASE_ANON_KEY = "YOUR_ANON_KEY";
```

Once both are present, the app switches from the demo localStorage mode to the real Supabase mode.

### 3. Create the database tables
In Supabase SQL editor, create the tables used by the app:

```sql
create table if not exists profiles (
  id uuid primary key,
  first_name text,
  last_name text,
  email text,
  phone text,
  address text,
  business_name text,
  account_type text,
  created_at timestamptz default now()
);

create table if not exists applications (
  id bigint generated by default as identity primary key,
  application_id text unique,
  user_id uuid references auth.users(id),
  motorcycle_id bigint,
  motorcycle_name text,
  motorcycle_price numeric,
  repayment_frequency text,
  weekly_payment numeric,
  amount_paid numeric default 0,
  balance numeric default 0,
  status text default 'Under Review',
  created_at timestamptz default now()
);
```

### 4. Enable access
Create a row-level policy or allow authenticated users to read/write their own profile rows.

For demo mode, the app still works with browser localStorage and does not require Supabase.

### 5. View registered users
Open `admin.html` after configuration to see all users in the live database.
